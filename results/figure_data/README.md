# Article-reported figure coordinates

These CSV files contain numeric coordinates explicitly printed in the article
source for Figures 2, 3, 5, 6, and 7. They are labeled
`reported_in_article` and may be replotted with
`scripts/plot_reported_figures.py`.

Figure 1 is a conceptual architecture diagram and Figure 4 is a qualitative
montage; neither image is duplicated here. The journal PDF is the authoritative
visual presentation.
